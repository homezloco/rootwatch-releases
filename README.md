# rootwatch-releases

Public binary releases for RootWatch's desktop app (the source repo is
private). AppImage installs auto-update from this repo via electron-updater.

Each release carries: `RootWatch-x.y.z.AppImage`,
`rootwatch-desktop_x.y.z_amd64.deb`, `rootwatch-desktop_x.y.z_amd64.snap`,
and `latest-linux.yml` (updater manifest).
